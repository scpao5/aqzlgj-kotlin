# 暗区指令工具 (Arena Breakout Command Tool)

[简体中文](README.zh-CN.md) | English

A command helper tool for the mobile game *Arena Breakout*, rewritten with **Kotlin + Jetpack Compose**. Features a floating window, categorized commands (20,000+), global search, one-tap copy/execute (Root & non-Root), segmented rendering, and dual UI themes (Miuix / Material).

## Features

- 6 categories of commands (2万+ entries)
- Global search with real-time filtering
- One-tap copy / execute (Root `su -c` broadcast or plain broadcast)
- In-game floating window (draggable, expand animation, search, execute, theme aware)
- Segmented rendering for large lists
- Miuix / Material themes with dark mode
- Global switches (hide toasts, hide update dialog)

## Build

```bash
./gradlew :app:assembleDebug
```
