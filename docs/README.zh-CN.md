# 暗区指令工具

[English](README.md) | 简体中文

## 介绍

**暗区指令工具** 是一款为《暗区突围》开发的指令辅助工具，基于 Kotlin + Jetpack Compose 重写，界面风格参考 KernelSU Manager（Miuix / Material 双主题）。

## 功能

- 六大分类指令浏览（2 万+ 条）
- 全局搜索（实时过滤、分类徽章）
- 一键复制 / 一键执行（Root 与免 Root 自动切换）
- 游戏内悬浮窗（拖动、展开动画、搜索、分类、执行、主题适配）
- 分段渲染（大列表懒加载）
- Miuix / Material 双界面风格 + 暗色适配
- 全局开关（隐藏 Toast、隐藏更新弹窗）

## 使用

1. 授予悬浮窗与通知权限
2. 「命令」页浏览 / 搜索指令
3. 「悬浮窗」开启游戏内悬浮窗

## 构建

```bash
./gradlew :app:assembleDebug
```
